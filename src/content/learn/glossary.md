# 5. Glossary

Terms marked (RBI) are defined in the RBI (Bharat Bill Payment System) Directions, 2024. Terms marked (NBBL) come from NBBL's website. Unmarked terms are general industry usage.

| Term | Meaning |
|---|---|
| BBPS | Bharat Bill Payment System: an integrated bill payment platform over multiple channels and payment modes (RBI) |
| Bharat Connect | Brand NBBL uses on its website alongside BBPS; I could not confirm a rebrand date (NBBL) |
| NBBL | NPCI Bharat BillPay Limited, the authorised central unit (RBI) |
| BBPCU | Bharat Bill Pay Central Unit, the role NBBL performs (RBI) |
| BBPOU | A BBPS participant; may be a BOU, a COU or both (RBI) |
| BOU | Biller Operating Unit: onboards billers (RBI) |
| COU | Customer Operating Unit: customer interface for paying bills (RBI) |
| Agent institution | Entity certified by NBBL providing the customer interface (RBI) |
| Agent | Customer touchpoint such as a branch or outlet (NBBL) |
| Biller aggregator | Aggregates billers so they can connect to a BOU (RBI) |
| TSP | Technology service provider certified by NBBL; no funds may flow through it (RBI) |
| Sponsor bank | Scheduled commercial bank that settles with NBBL for non-bank BBPOUs (RBI) |
| Escrow account | Account non-bank BBPOUs must hold for BBPS only (RBI) |
| BBPS reference number | Number each transaction carries from payment initiation; used for disputes (RBI) |
| Biller MDM | Biller master data file published by the central unit (NBBL) |
| Bill fetch | Retrieving the bill before payment is initiated (RBI) |
| Guaranteed settlement | NBBL's guarantee of settlement for transactions routed through it (RBI) |
| ODR | Online dispute resolution framework the complaint system aligns with (RBI) |
| TAT | Turnaround time for failed-transaction handling and compensation (RBI circular of 20 Sep 2019) |
| BOAT | Biller onboarding and automated testing portal (NBBL) |
| CertPlay | Automated certification portal for operating units (NBBL) |
| Canvas | Central dispute management portal (NBBL) |
| Clearing and settlement | Working out and moving money between institutions; undertaken by NBBL (RBI) |
| Reconciliation | Matching each party's records of the same transactions |
